Démarrage

Installer le paquet, charger les styles et les composants, puis utiliser les balises rds-*.

Installation

pnpm add {{npm}}
# ou : npm install {{npm}}

Styles généraux

Tokens --ds-*, polices et styles de base. À charger une fois, avant les composants. 

// Avec un bundler (vite, webpack, esbuild…)
import '{{npm}}/css';
<!-- Sans bundler -->
<link rel="stylesheet" href="node_modules/{{npm}}/dist/design-system.css" />
// Dans un projet LESS
@import '{{npm}}/less';

Version minifiée : {{npm}}/css/min.

Composants

import '{{npm}}'; // enregistre tous les custom elements rds-*
import { toast, setTheme } from '{{npm}}';
<rds-primary-button icon-before="house">Accueil</rds-primary-button>
<rds-input name="nom" required>Nom <span slot="hint">Obligatoire</span></rds-input>

Un bundle ESM minifié est aussi fourni : {{npm}}/bundle. Les icônes (Lucide, fichiers SVG) sont chargées par nom depuis un dossier icons/ placé à côté du module (dist/icons ou out/icons).

Si votre bundler déplace le module, indiquez le dossier des icônes avec la fonction setIconsPath() exportée par le paquet.

Éviter le flash au chargement

Avant l’exécution du JavaScript, les balises rds-* ne sont pas encore définies. Le CSS général les masque (en réservant leur place) jusqu’à leur définition, et fournit déjà les styles des liens de l’en-tête, de la navigation, du pied de page, du fil d’Ariane et des tableaux. Pour que cela fonctionne :

  • chargez le CSS général avant le script ;
  • placez le <script type="module"> dans le <head> ;
  • ajoutez un <link rel="modulepreload"> vers le bundle pour le récupérer plus tôt.
<link rel="stylesheet" href="design-system.css" />
<link rel="modulepreload" href="rotomeca-design-system.js" />
<script type="module" src="rotomeca-design-system.js"></script>

Si le script ne se charge pas, le contenu est rendu visible après 2 secondes.

Thème clair / sombre

Le thème sombre « Sous-bois » s’active avec data-theme="dark" sur <html>, ou avec l’API setTheme('light' | 'dark' | 'system'). Le composant rds-theme-switcher propose cette bascule à l’utilisateur et mémorise son choix.

Personnalisation

Les composants ne lisent que des propriétés CSS --ds-* : le thème se surcharge en les redéfinissant, sans toucher aux composants. 

:root {
  --ds-background-action-primary: #2f5d50;
  --ds-radius-lg: 0.5rem;
}

La liste des tokens est détaillée dans Tokens & thème.

Accessibilité

  • Rôles et attributs ARIA, navigation complète au clavier, focus visible.
  • Contrôles de formulaire associés au formulaire (ElementInternals) : valeur, validité, réinitialisation.
  • Les animations respectent prefers-reduced-motion.
